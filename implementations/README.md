# Implementations

No runnable implementation has been added yet.

The [Performance Factory reconstruction proposal](../case-studies/openai-performance-factory/reconstruction.md) defines a possible first example: a local coordinator with persistent records, deterministic workers, and repeatable failure scenarios.

When implemented, `minimal-factory/` should include a README, package metadata, source code, and checks for its recovery guarantees. Its README must distinguish simulated behavior from real integrations. A directory name or an empty package is not a working implementation.
