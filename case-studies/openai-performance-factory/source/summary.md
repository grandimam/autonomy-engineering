# Source summary

OpenAI describes an automation system built around persistent tasks, configurable workflows, a dispatcher, cloud Codex execution, and event subscriptions. An alert starts an investigation; agents record evidence, challenge diagnoses, and propose changes. Engineers review changes, and agents subsequently check production recovery. Waiting work resumes when relevant events arrive. [Source](https://openai.com/index/how-openai-performance-factory-keeps-chatgpt-fast/)

The authors report more than 1,700 investigations and over 600 root-caused cases in just over three months. Those are reported investigation outcomes, not counts of automatically shipped fixes. They describe historical evaluations, readable handoffs, and recurring tool-failure detection as part of operating the system. [Source](https://openai.com/index/how-openai-performance-factory-keeps-chatgpt-fast/)
