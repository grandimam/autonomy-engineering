# Patterns

A pattern should describe a recurring problem, the conditions in which it applies, its mechanism, failure modes, and a worked example.

Candidate topics from the repository outline: event-to-task conversion, workflow state machines, lease-based dispatch, resumable execution, adversarial verification, event subscriptions, and self-healing.

These are candidate topics, not claims that the studied system implements every named mechanism. The [reconstruction proposal](../case-studies/openai-performance-factory/reconstruction.md) is an initial place to test coordination patterns before promoting them to standalone guides.
